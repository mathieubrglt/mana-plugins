# Four learnings that govern the corpus

These four govern how learnings are written. Store them under `learning/`
keys in a store that does not hold them yet.

```
reject learnings whose strategy is not a concrete check
learned: abstraction can launder emptiness; a vague strategy means the lesson was diluted, not distilled
impact: confirmed=a truism admitted because its form looked distilled | suspected=corpus dilution, reader trust decay
strategy: run the admission gate; reject when the agent cannot act on the learning
```

```
admit only lessons that change a future decision
learned: reuse value is recurrence times non-obviousness; what competent people already do changes nothing
impact: confirmed=one of three sampled learnings failed the test | suspected=none
strategy: name a decision the learning changes that a competent person would otherwise get wrong
also: an incident with no checkable directive yields an action item, not a learning
```

```
generalize one abstraction step at a time
learned: each abstraction step widens applicability and loses precision; skipping steps produces slogans
impact: confirmed=one clean generalization, one that produced a platitude | suspected=none
strategy: generalize until the strategy stops being a concrete check; keep the last checkable version
```

```
write learnings in literal terms, not figurative ones
learned: idioms compress meaning for one language community and misparse outside it; literal wording keeps one reading
impact: confirmed=a metaphor required explanation and rewrite | suspected=silent misreads by non-native or automated readers
strategy: rewrite any figurative phrase literally; a reader unfamiliar with the language's idioms must parse every line
```
